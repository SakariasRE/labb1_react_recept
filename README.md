Det här är enkel recept applikation som jag gjorde med dummyjson API där syftet är att ta fram och lägga till recept på olika maträtter och kunna se vilka ingredienser som behövs och svårighetsgrad

jag har GET med fetch där alla recept hämtas. POST och PATCH använder handleRecipeSubmit för att lägga till och ändra recept. DELETE hanteras med handleRecipeDelete om du vill ta bort något recept.
